# YHWH

**Android Based God Simulator**

An ambitious Android application that simulates a god-like experience, written entirely in Kotlin.

## Overview

YHWH is a creative Android simulator that explores the concept of divine control and omniscience through an interactive mobile experience. The application is built using Kotlin, leveraging modern Android development practices.

## Features

- 🎮 Interactive simulation mechanics
- 📱 Native Android experience
- ⚙️ Kotlin-based implementation
- 🎯 Intuitive user interface

## Getting Started

### Prerequisites

- Android Studio (latest version recommended)
- Android SDK 21 or higher
- Kotlin 1.9 or higher
- Gradle 7.0 or higher

### Installation

1. Clone the repository:
```bash
git clone https://github.com/madmaxlgndklr/YHWH.git
cd YHWH
```

2. Open the project in Android Studio:
```bash
android-studio .
```

3. Build the project:
```bash
./gradlew build
```

4. Run on an emulator or physical device:
```bash
./gradlew installDebug
```
